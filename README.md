# Student Management App

A Flutter class project covering Weeks 1-7 concepts:

- Login and student registration forms
- Navigation with a shared app drawer
- SQLite student CRUD with search
- Attendance marking and reports
- External API consumption using `http`
- Settings and dashboard summary screens

## Demo Login

Use the demo account to enter the dashboard before adding students:

```text
Email: admin@sms.local
Password: admin123
```

Registered students can also sign in using the email and password saved during registration.

## Run

```bash
flutter pub get
flutter run
```

## Checks

```bash
flutter analyze
flutter test
```
